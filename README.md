# Chatterbox — пространство класса

Версия для Netlify: аккаунты по уникальному имени/нику и пароль в профиле; панель учителя с регистрациями, управлением группами и чатами; групповой текстовый чат, загрузка вложений любых типов и видеозвонок до 6 участников. HTML-вложения открываются во встроенном изолированном просмотрщике. Видимых ID нет. Добавлены PWA-манифест, service worker, мобильная компоновка и Liquid Glass-стиль в цветах флага Великобритании. Новая иконка пользователя используется для favicon, PWA, экранов входа и приложенческой оболочки.

## Установка на уже существующий Netlify-сайт

1. Скачайте архив `chatterbox-netlify.zip` и распакуйте его. На верхнем уровне папки должны лежать `netlify.toml`, `package.json`, папки `public/` и `netlify/`.
2. Войдите в Netlify и откройте свой Netlify-проект. На странице **Deploys** выберите ручное размещение / **Deploy manually** и перетащите туда **всю распакованную папку проекта**, а не только `public/`. Будучи залогиненной, Netlify запустит сборку и включит серверную функцию.
3. Приложение использует Netlify Database. При поддерживаемом тарифе Netlify она подключается при публикации проекта; если база ещё не создана, откройте страницу **Database** проекта и выберите **Create a database**. Схема таблиц создаётся автоматически при первом запросе. Если Netlify попросит новый deploy после подключения базы — выполните его.
4. Войдите как ученик по имени, затем нажмите **«Для разработчика»**, войдите в панель учителя, создайте группу и распределите ученика. Проверить второй профиль можно в другом браузере или на телефоне.

### Вход администратора

Данные для входа, которые вы указали в переписке, уже прописаны **только в серверной функции** `netlify/functions/api.mjs`; браузерный `public/app.js` пароля не содержит, переменные в панели Netlify задавать не нужно. Если захочется изменить данные позже — отредактируйте `ADMIN_USERNAME` / `ADMIN_PASSWORD` в этой функции и опубликуйте новую версию.

Важно: не выкладывайте сам ZIP или исходную папку в публичный репозиторий и не отправляйте их посторонним — в серверном исходнике лежат данные для входа. Посетителям сайта серверная функция исходник не отдаёт.

Netlify принимает проектные папки через ручную публикацию; для серверных функций нужен deploy, запускающий сборку, а не публикация только готовых HTML-файлов. Инструкция Netlify по ручной публикации: [Deploy with drag and drop](https://docs.netlify.com/deploy/create-deploys/).

## Установка как приложения

Сайт должен открываться по HTTPS (адрес `*.netlify.app` уже использует HTTPS).

- **iPhone/iPad:** Safari → **Поделиться** → **На экран “Домой”** → **Добавить**.
- **Android:** Chrome → меню **⋮** → **Установить приложение** или **Добавить на главный экран**.

При первом открытии браузер должен загрузить сайт онлайн. Service worker кэширует только оболочку приложения; API и база требуют сети.

## Как устроен вход и защита

- Имя ученика уникально без учёта регистра и лишних пробелов. Повторный вход с тем же именем открывает тот же аккаунт; если к нему добавлен пароль, его нужно ввести.
- Пароль можно пропустить при первом входе и добавить позже через **Аккаунт**. Пароли учеников хранятся в базе в виде солёного хэша. Если у аккаунта нет пароля, одно совпадение имени достаточно для входа — добавьте пароль, чтобы защитить аккаунт при входе с других устройств.
- Браузер хранит случайную сессию, на сервере хранится её хэш. Без пароля после очистки данных сайта доступ можно восстановить вводом того же уникального имени; с паролем можно войти под этим именем на другом телефоне.
- Вход администратора проверяется **на серверной Netlify Function**, а не в браузерных файлах. Админ-сессия хранится на сервере и истекает через 8 часов.
- Учитель может открыть любую группу, переключать чаты, писать сообщения и отправлять файлы; ученик видит чат только назначенной ему группы.
- Кнопка **＋** (прикрепить файл) принимает файлы любых типов размером до 4 МБ. Для `.html` / `.htm` есть **Открыть HTML**: файл показывается на весь экран в изолированном iframe без доступа к аккаунту; есть кнопки разворота и закрытия.
- Кнопка **Видеосвязь** открывает шаг с объяснением и отдельной кнопкой запроса разрешения камеры/микрофона; нажмите её, затем в системном запросе браузера выберите «Разрешить». Если доступ уже отклонён, включите камеру и микрофон в настройках сайта рядом с адресом и повторите. Нужны HTTPS и открытие сайта напрямую в Safari/Chrome. Звонок — до 6 участников; при двух видео участники занимают всю доступную область. Есть ручной полноэкранный режим и **Показать экран**; кнопка демонстрации открывает системный выбор дисплея/окна, на телефонах доступность зависит от браузера и ОС; Safari/Chrome на iPhone могут не предоставлять сайтам захват экрана. Это системное ограничение нельзя обойти из веб-страницы. Сигнализация проходит через функции и базу Netlify, медиапоток идёт напрямую между устройствами.
- Вкладка **English · ИИ** — учебный помощник, который отвечает простым английским, объясняет правила и просит решить похожее упражнение, а не даёт готовый ответ. Добавлен фотореалистичный портрет учительницы по присланному фото в мягком студийном стиле с британской шапочкой; во время речи работает простая анимация рта, а на просьбы списать или получить готовое решение появляются нахмуренные брови. Ответы можно озвучивать автоматически или кнопкой **Listen**; браузер предпочитает голос English (UK), если он доступен. Качество зависит от голосов браузера/устройства, а на некоторых телефонах автозапуск может требовать нажатия **Listen**. Используется встроенная озвучка браузера, без отдельного TTS-сервиса. Для ИИ — бесплатный анонимный endpoint Pollinations без API-ключа; запросы и часть истории разговора отправляются внешнему сервису. Лимиты, скорость и доступность определяет провайдер; сервис может временно не отвечать.
- Вкладка **Переводчик** переводит в обе стороны (английский ↔ русский). Для фото текст распознаётся OCR-моделью в браузере; изображение не загружается, во внешний переводчик уходит только распознанный текст. При первом использовании выбранного языка браузер скачает OCR-модель (порядка 9–11 МБ); для распознавания нужна сеть. Лучше всего работает с чётким печатным текстом, не с рукописью. Истории ИИ и переводов сохраняются локально в браузере, а не в Netlify Database.
- Для соединения используются публичные STUN-серверы. Некоторые сети/провайдеры блокируют P2P или STUN; без отдельного TURN-сервера видеозвонок в любой сети гарантировать нельзя. Ограничение особенно важно при тестировании из сетей с фильтрацией.
- При удалении группы ученики остаются в списке без группы, сообщения и файлы этой группы удаляются. При удалении ученика его аккаунт и текстовые сообщения удаляются.
- Из-за лимита Netlify Functions для загрузки в этой версии установлен размер файла до 4 МБ; форматы не ограничиваются.
- На бесплатном плане Netlify действуют лимиты; если лимит исчерпан, сервис может приостановить работу до следующего расчётного периода. Netlify Database на бесплатном плане также может засыпать при бездействии. Это не круглосуточная гарантия без перерывов.

## Если появляется ошибка подключения, а не серое окно

Сам интерфейс загружается отдельно и показывает сообщение на странице. Для регистрации/групп должны быть доступны Netlify Function и Database. Если интерфейс пишет, что база не подключена, проверьте шаг 3 и выполните новый deploy. Пароль администратора находится в серверной функции; задавать `ADMIN_USERNAME`/`ADMIN_PASSWORD` в настройках Netlify не нужно.

## Состав

- `public/` — интерфейс, PWA-манифест, service worker, иконки и аватар-портреты English-помощника.
- `public/avatars/` — портрет по присланному фото в мягком студийном стиле с британской шапочкой; мимика и речь анимируются поверх портрета в CSS.
- `netlify/functions/api.mjs` — серверная регистрация, админ-вход, группы и сообщения.
- `assets/logo-original-transparent-1024.png` — исходная прозрачная иконка, переданная пользователем; на её основе собран набор Union Jack иконок.
- `netlify.toml`, `package.json` — настройки сборки Netlify.
